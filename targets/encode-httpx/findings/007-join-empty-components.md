# Finding: `URL.join` loses present-but-empty query/fragment components — inherited `urllib.parse.urljoin` behaviour

- Target / property: encode/httpx `main` @ `b5addb6` — property U8 (join metamorphic relations) as originally stated. Counterexamples:
  - Base `URL("http://e.org/?")` (empty query, trailing `?`): `base.join("#frag")` → query becomes absent (`str` `"http://e.org/#frag"`) instead of inheriting the empty query (`"http://e.org/?#frag"` per RFC 3986 §5.2.2, which inherits the base query whenever the reference query is undefined).
  - Base `URL("http://e.org/#a")` (any fragment, empty or not): `base.join("")` → returns the base *with* its fragment (`"http://e.org/#a"`) instead of dropping it (an empty reference's fragment is undefined, so per RFC 3986 §5.2.2 the target has no fragment).
  - Base with a scheme outside `urllib`'s resolution tables, e.g. `URL("a+b-c.d://0/?a=")`: `base.join("#frag")` returns the reference `URL("#frag")` unresolved — `urljoin` only resolves references for known schemes. (Out of httpx's HTTP scope, but it means `join`'s behaviour is scheme-dependent in a way the docstring does not mention.)
- Observed vs expected: the full RFC 3986 §5.4 example table (37 normal + abnormal cases) passes, and every non-empty component case behaves. Only the present-but-empty components — the distinction `_urlparse`'s module docstring singles out as a design goal ("It properly differentiates between an empty querystring and an absent querystring") — are flattened by resolution.
- Verdict: **wrong property** as stated (over-strong) — not counted as a confirmed httpx bug.
- Reasoning: `URL.join` is by construction `URL(urljoin(str(self), str(URL(url))))` (`httpx/_urls.py`); all three deviations are stdlib `urljoin` semantics (it does not distinguish empty from absent query, keeps the base fragment for empty references, and only resolves known schemes), inherited wholesale rather than introduced by httpx code. httpx documents `join` only as "Return an absolute URL, using this URL as the base" — it does not claim §5.2-exact resolution — so the property's RFC framing was stronger than the documented contract. Recorded because the interactions are still user-visible: httpx preserves a trailing `?` everywhere *except* across a redirect-style `join`, and a fragment survives an empty-reference join, so code that round-trips URLs through `join` can silently change a URL's string form or meaning. The harness test now encodes the actual (delegation) contract: web schemes only, empty reference = identity, and the empty-query carve-out on fragment joins.
